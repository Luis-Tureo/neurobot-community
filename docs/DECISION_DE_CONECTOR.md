# Decisión de conector

| Uso | Conector | Motivo |
| --- | --- | --- |
| Comunidad en grupos | WhatsApp Web | Permite trabajar con la sesión comunitaria ya vinculada y detectar grupos. |
| Atención comercial privada | WhatsApp Cloud API | Usa la integración oficial para flujos comerciales, webhooks y componentes interactivos compatibles. |

Neurobot queda fijado a WhatsApp Web y al modo `COMMUNITY_GROUPS`. Los perfiles comerciales se crean separados y no reutilizan su sesión, base operativa ni identidad.
